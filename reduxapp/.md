# Redux Toolkit

## Installation

```bash
npm install @reduxjs/toolkit react-redux
```

---

# What is Redux?

Redux is a **state management library** used to manage and share data across the entire React application.

---

# Why Redux?

Without Redux, data is passed from one component to another using **props**.

This is called **Prop Drilling**.

### Problems with Prop Drilling

- Too many props
- Hard to maintain
- Difficult to debug
- Components become dependent on each other

Redux solves this problem by providing a **centralized store** where every component can directly access the required data.

# Store

The **Store** is the central storage of the application.

It stores all global state.

Example:

```javascript
{
  auth: {
    isAuthenticated: false,
    user: null
  }
}
```

---

# Slice

A **Slice** is a small part of the Redux Store.

Example:

```
Store

├── auth
├── cart
├── products
├── theme
└── notification
```

Each feature has its own slice.

---

# State

State represents the **current data** stored inside Redux.

### Before Login

```javascript
{
  isAuthenticated: false,
  user: null
}
```

### After Login

```javascript
{
  isAuthenticated: true,
  user: {
    name: "Admin",
    email: "admin@gmail.com"
  }
}
```

Whenever data changes, Redux updates the state automatically.

---

# Reducer

A **Reducer** is a function responsible for updating the Redux state.

Example:

```
Current State
      +
Action
      ↓
Reducer
      ↓
New State
```

---

# Action

An **Action** tells Redux **what happened**.

Example:

```javascript
dispatch(login(user));
```

or

```javascript
dispatch(logout());
```

---

# Provider

The **Provider** makes the Redux Store available to the entire React application.

```
Provider
    │
    ▼
React App
    │
    ▼
All Components
```

Without `Provider`, components cannot access the Redux Store.

---

# useSelector()

`useSelector()` is used to **read data** from the Redux Store.

Example:

```javascript
const user = useSelector((state) => state.auth.user);
```

Think of it as:

> Read data from Redux.

---

# useDispatch()

`useDispatch()` is used to **update the Redux Store** by dispatching actions.

Example:

```javascript
dispatch(login(user));
```

Think of it as:

> Send an action to Redux.

---

# useSelector vs useDispatch

| useSelector() | useDispatch() |
|---------------|---------------|
| Reads data | Updates data |
| Returns current state | Dispatches actions |
| Does not change state | Changes state through reducers |

# Auto Authentication

Redux state is stored in **memory**.

When the page refreshes:

```
Refresh

↓

Redux Store Clears

↓

User Logs Out
```

To prevent this, save the user in **localStorage**.

```
Login

↓

Redux Store Updated

↓

Save User in localStorage

↓

Refresh

↓

Read localStorage

↓

Restore Redux State

↓

User Remains Logged In
```

---

# Logout Flow

```
Logout

↓

Clear Redux State

↓

Remove User from localStorage

↓

Navigate to Login
```

# Important Points

- Redux is a **state management library**.
- Store holds the global state.
- Slice is a feature-specific part of the store.
- State represents the current data.
- Actions describe **what happened**.
- Reducers update the state.
- `useSelector()` reads data.
- `useDispatch()` updates data.
- `Provider` connects React with Redux.
- `localStorage` helps restore authentication after a page refresh.
