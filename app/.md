# Tailwind CSS Cheat Sheet

## Background Colors

| Class | Description |
|--------|-------------|
| `bg-red-500` | Red background |
| `bg-blue-600` | Blue background |
| `bg-green-500` | Green background |
| `bg-gray-100` | Light gray background |
| `bg-gray-900` | Dark gray background |
| `bg-white` | White background |

---

## Text

| Class | Description |
|--------|-------------|
| `text-white` | White text |
| `text-black` | Black text |
| `text-center` | Center align text |
| `text-left` | Left align text |
| `text-right` | Right align text |
| `text-sm` | Small text |
| `text-lg` | Large text |
| `text-2xl` | Extra large text |
| `text-4xl` | Very large text |
| `font-bold` | Bold text |
| `font-semibold` | Semi-bold text |

---

## Margin

| Class | Description |
|--------|-------------|
| `m-4` | Margin on all sides |
| `mt-5` | Margin top |
| `mb-5` | Margin bottom |
| `ml-5` | Margin left |
| `mr-5` | Margin right |
| `mx-auto` | Center horizontally |

---

## Padding

| Class | Description |
|--------|-------------|
| `p-5` | Padding all sides |
| `px-6` | Horizontal padding |
| `py-4` | Vertical padding |
| `pt-5` | Padding top |
| `pb-5` | Padding bottom |

---

## Width

| Class | Description |
|--------|-------------|
| `w-full` | 100% width |
| `w-80` | Fixed width |
| `w-1/2` | 50% width |
| `w-screen` | Full screen width |

---

## Height

| Class | Description |
|--------|-------------|
| `h-screen` | Full viewport height |
| `h-full` | 100% parent height |
| `h-60` | Fixed height |

---

## Flexbox

| Class | Description |
|--------|-------------|
| `flex` | Enable Flexbox |
| `flex-col` | Vertical layout |
| `flex-row` | Horizontal layout |
| `justify-center` | Center horizontally |
| `justify-between` | Space between items |
| `items-center` | Center vertically |
| `gap-5` | Space between items |

Example:

```html
<div class="flex justify-center items-center h-screen">
    Content
</div>
```

---

## Grid

| Class | Description |
|--------|-------------|
| `grid` | Enable Grid |
| `grid-cols-2` | 2 Columns |
| `grid-cols-3` | 3 Columns |
| `grid-cols-4` | 4 Columns |
| `gap-6` | Gap between items |

Example:

```html
<div class="grid grid-cols-3 gap-6">
```

---

## Border

| Class | Description |
|--------|-------------|
| `border` | Add border |
| `border-2` | 2px border |
| `rounded` | Small rounded corners |
| `rounded-lg` | Large rounded corners |
| `rounded-full` | Fully rounded |

---

## Shadow

| Class | Description |
|--------|-------------|
| `shadow` | Small shadow |
| `shadow-md` | Medium shadow |
| `shadow-lg` | Large shadow |
| `shadow-xl` | Extra large shadow |

---

## Hover

| Class | Description |
|--------|-------------|
| `hover:bg-red-500` | Change background on hover |
| `hover:text-white` | Change text color |
| `hover:scale-105` | Zoom effect |
| `hover:shadow-lg` | Increase shadow |

---

## Transition

| Class | Description |
|--------|-------------|
| `transition` | Enable transition |
| `duration-300` | 300ms animation |
| `duration-500` | 500ms animation |
| `ease-in-out` | Smooth animation |

Example:

```html
<button class="bg-blue-600 hover:bg-blue-700 transition duration-300">
    Login
</button>
```

---

## Responsive Design

| Prefix | Screen Size |
|--------|-------------|
| `sm:` | ≥ 640px |
| `md:` | ≥ 768px |
| `lg:` | ≥ 1024px |
| `xl:` | ≥ 1280px |
| `2xl:` | ≥ 1536px |

Example:

```html
<div class="text-sm md:text-xl lg:text-3xl">
    Responsive Text
</div>
```
